# US-pipeline.stage.auto-advance-task: Автоматическое прохождение задачи по стадиям

```gherkin
@US-pipeline.stage.auto-advance-task @HF1.1 @HF5.1 @UC-pipeline.stage.auto-advance-task @P0 @pipeline @stage @agent
Feature: US-pipeline.stage.auto-advance-task Автоматическое прохождение задачи по стадиям

  Background:
    Given в проекте включён автономный режим выполнения задач
    and для проекта настроен рабочий runtime-профиль

  Scenario: Система автоматически продвигает задачу по конвейеру
    Given задача находится в backlog и готова к запуску
    When внешний наблюдатель ожидает очередной цикл обработки
    Then задача переходит в следующую рабочую стадию без ручного запуска
    and внешний наблюдатель видит согласованное изменение стадии в API и событиях обновления

  Scenario: Задача не продвигается, если уже обрабатывается другим исполнителем
    Given задача уже находится в активной обработке
    When внешний наблюдатель проверяет состояние после цикла обработки
    Then система не запускает дублирующую обработку этой задачи
    and стадия задачи не меняется повторно

  Scenario: Сбой выполнения не теряет состояние задачи
    Given задача запущена в автоматическую обработку
    When на этапе выполнения происходит ошибка
    Then задача переводится в контролируемое состояние, требующее внимания
    and внешний наблюдатель получает диагностируемую причину состояния
```
