# US-pipeline.manual-override.intervene-task-stage: Ручное управление стадией задачи

```gherkin
@US-pipeline.manual-override.intervene-task-stage @HF1.7 @UC-pipeline.manual-override.intervene-task-stage @P1 @pipeline @manual-override @gui
Feature: US-pipeline.manual-override.intervene-task-stage Ручное управление стадией задачи

  Background:
    Given пользователь открыл детальный просмотр задачи

  Scenario: Пользователь выполняет допустимое ручное действие
    Given для текущей стадии задачи доступно ручное действие
    When пользователь запускает действие в интерфейсе
    Then стадия задачи обновляется в соответствии с правилом перехода
    and изменение становится видимым в доске и в истории задачи

  Scenario: Недопустимое действие отклоняется
    Given выбранное действие недоступно для текущей стадии
    When пользователь пытается выполнить это действие
    Then система отклоняет действие без изменения стадии
    and пользователь получает понятное сообщение о причине отказа

  Scenario: Пользователь восстанавливает задачу из блокировки
    Given задача находится в blocked_external и доступно действие возврата
    When пользователь выполняет действие возврата из блокировки
    Then задача возвращается в рабочую стадию
    and выполнение может быть продолжено

  Scenario: Администратор выполняет ручное действие для чужой задачи
    Given администратор не является текущим исполнителем задачи
    When администратор запускает допустимое ручное действие
    Then система разрешает действие в рамках административных полномочий
```
