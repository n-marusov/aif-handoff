# US-auth.registration.sign-up-participant: Регистрация, вход и выход участника

```gherkin
@US-auth.registration.sign-up-participant @HF9.1 @UC-auth.registration.sign-up-participant @P1 @auth @registration @gui
Feature: US-auth.registration.sign-up-participant Регистрация, вход и выход участника

  Background:
    Given в системе включён режим участников

  Scenario: Новый участник регистрируется и получает доступ к системе
    Given пользователь находится на странице входа
    When пользователь заполняет форму регистрации и отправляет её
    Then учётная запись создаётся
    and пользователь может войти в систему под своими данными

  Scenario: Зарегистрированный участник входит в систему
    Given участник зарегистрирован
    When участник вводит корректные учётные данные
    Then участник получает аутентифицированную сессию
    and может выполнять действия в интерфейсе согласно своим правам

  Scenario: Неверные учётные данные отклоняются
    Given участник вводит неверный пароль
    When участник отправляет форму входа
    Then вход отклоняется
    and интерфейс показывает понятное сообщение об ошибке

  Scenario: Участник завершает сессию
    Given участник аутентифицирован
    When участник выполняет выход из системы
    Then сессия завершается
    and доступ к защищённым операциям требует повторного входа
```
