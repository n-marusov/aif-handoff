# US-auth.roles.assign-participant-role: Управление ролями и доступом участников

```gherkin
@US-auth.roles.assign-participant-role @HF9.2 @UC-auth.roles.assign-participant-role @P1 @auth @roles @gui
Feature: US-auth.roles.assign-participant-role Управление ролями и доступом участников

  Background:
    Given администратор открыл управление участниками

  Scenario: Администратор изменяет роль участника
    Given в системе есть участники с назначенными ролями
    When администратор меняет роль участника
    Then новая роль применяется
    and права участника соответствуют новой роли в последующих действиях

  Scenario: Администратор отключает участника
    Given участник активен
    When администратор деактивирует участника
    Then участник не может войти в систему до повторной активации

  Scenario: Участник с ролью member видит только разрешённый ему контур работ
    Given участник имеет роль member
    When участник открывает рабочее пространство
    Then участник видит только назначенные ему задачи и доступные ему проекты

  Scenario: Участник меняет свой пароль
    Given участник аутентифицирован
    When участник выполняет смену пароля
    Then новый пароль начинает действовать для следующих входов
```
