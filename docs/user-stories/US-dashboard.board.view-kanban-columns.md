# US-dashboard.board.view-kanban-columns: Просмотр задач по стадиям на Kanban-доске

```gherkin
@US-dashboard.board.view-kanban-columns @HF2.1 @UC-dashboard.board.view-kanban-columns @P0 @dashboard @board @gui
Feature: US-dashboard.board.view-kanban-columns Просмотр задач по стадиям на Kanban-доске

  Background:
    Given пользователь выбрал проект в ProjectSelector

  Scenario: Пользователь видит текущее состояние проекта по стадиям
    Given в проекте есть задачи на разных стадиях
    When пользователь открывает Kanban-доску проекта
    Then пользователь видит колонки стадий и карточки задач в соответствующих колонках
    and в карточке задачи видны ключевые атрибуты для принятия решения (название, приоритет, исполнитель, последняя активность)

  Scenario: Пользователь меняет порядок задач в колонке
    Given доска отображает список задач в режиме kanban
    When пользователь перетаскивает карточку задачи на новую позицию
    Then новый порядок карточек сохраняется
    and после обновления доски пользователь видит тот же порядок

  Scenario: Пользователь фильтрует задачи для фокусировки на нужном срезе
    Given на доске доступна фильтрация
    When пользователь задаёт фильтр по статусу, приоритету, исполнителю или тегам
    Then на доске отображаются только задачи, соответствующие выбранным условиям

  Scenario: Пользователь переключает способ представления задач
    Given пользователь работает с Kanban-доской
    When пользователь переключает отображение в list-режим
    Then задачи отображаются в списке с тем же набором данных по выбранному проекту
```
