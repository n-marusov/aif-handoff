# US-dashboard.detail.view-task-details: Детальный просмотр задачи

```gherkin
@US-dashboard.detail.view-task-details @HF2.3 @HF6.1 @UC-dashboard.detail.view-task-details @P0 @dashboard @detail @gui
Feature: US-dashboard.detail.view-task-details Детальный просмотр задачи

  Background:
    Given пользователь работает с проектом, содержащим задачи

  Scenario: Пользователь открывает детальную карточку задачи
    Given пользователь видит карточку задачи на доске
    When пользователь открывает задачу
    Then пользователь видит контекст задачи для работы и контроля
    and доступны описание, приоритет, текущая стадия, исполнитель и история изменений
    and доступны комментарии и результаты проверок
    and доступна информация об использовании runtime для этой задачи

  Scenario: Для задачи без плана раздел плана не мешает работе
    Given для задачи ещё не сформирован план
    When пользователь открывает детальный просмотр
    Then интерфейс не показывает пустой или вводящий в заблуждение блок плана

  Scenario: Пользователь добавляет комментарий к задаче
    Given пользователь открыл детальный просмотр задачи
    When пользователь отправляет комментарий
    Then комментарий сохраняется и отображается в ленте обсуждения задачи
```
