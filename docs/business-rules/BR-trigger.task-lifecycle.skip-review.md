# BR-trigger.task-lifecycle.skip-review — Ускоренный путь без проверок

> Задача, помеченная как не требующая ревью, проходит от реализации сразу к Done, минуя стадии Verify и Review.

## Правило

Для отдельных задач (низкий риск, тривиальное изменение) может быть установлен признак «без ревью». Такая задача не останавливается на стадиях проверки и ревью и переводится из Implementing напрямую в Done.

## Детализация

- Признак задаётся при создании или редактировании задачи и является осознанным исключением из стандартного конвейера.
- Отключение проверок не отменяет фиксацию изменений перед терминальной стадией.
- Признак не влияет на другие правила жизненного цикла: владение, аудит, обработку блокировок.
- По умолчанию проверки обязательны; ускоренный путь — явное исключение.

## Обоснование

Позволяет не тратить ресурсы проверок на изменения, где они не дают ценности, сохраняя обязательность проверок по умолчанию.
