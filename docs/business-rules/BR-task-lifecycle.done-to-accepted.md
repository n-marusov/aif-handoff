# BR-task-lifecycle.done-to-accepted — Приёмка результата

> Из стадии Done задача либо принимается (Accepted) — окончательно, — либо возвращается на доработку (Implementing).

## Правило

Решение по завершённой задаче принимает человек: принять результат или вернуть на доработку. Приёмка финальна и необратима; возврат на доработку возобновляет реализацию.

## Детализация

- Приёмка переводит задачу `Done → Accepted`; после этого задача не может быть изменена или передана.
- Возврат на доработку переводит `Done → Implementing` и помечает задачу как требующую переработки.
- Аналогично разрешаются задачи на стадии `Review`, переданные человеку: человек может принять результат или запросить изменения.
- Приёмка результата, реализованного автоматическим агентом, может сопровождаться фиксацией изменений во внешней VCS.
- Приёмка завершает владение задачей: терминальная задача не участвует в автоматическом конвейере.

## Обоснование

Разделение «результат готов» (Done) и «результат принят» (Accepted) оставляет окончательное решение за человеком и предотвращает бесконтрольное закрытие задач.
