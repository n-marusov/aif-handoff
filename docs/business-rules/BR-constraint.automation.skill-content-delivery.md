# BR-constraint.automation.skill-content-delivery — Полная доставка инструкций скилла модели

> При выполнении скилла (slash command) модель должна получить полный текст инструкций скилла, а не только имя команды. Названия скиллов без инструкций недопустимы.

## Правило

При выполнении любого скилла (например, `/aif-plan`, `/aif-implement`, `/aif-verify`) модель должна получить полный текст инструкций этого скилла в промпте, а не только имя команды. Если рантайм не поддерживает загрузку agent definitions (`supportsAgentDefinitions: false`), инструкции скилла должны быть встроены в текст промпта.

Недопустимо: `HANDOFF_MODE: 1\n/aif-plan full @path` без детальных инструкций скилла. Допустимо: полный промпт с описанием формата, структуры, ограничений и требований к выходу скилла.

## Детализация

- **Механизмы доставки:** agent definition (для рантаймов с `supportsAgentDefinitions: true`), `apiSkillExpansion` (автоматическая подстановка инструкций), fallback slash command (через `executeSubagentQuery`), или ручное включение инструкций в текст промпта.
- **Проверка:** если `usedFallbackSlashCommand = false`, `usedApiSkillExpansion = false` и `usedNativeSubagentWorkflow = false` одновременно — инструкции скилла НЕ были доставлены. Это нарушение правила.
- **Рантайм-адаптер:** при `supportsAgentDefinitions: false` (OpenRouter, API-транспорт) единственный способ доставки — явное включение инструкций в промпт.
- **Базовый набор инструкций** для каждого скилла должен включать: формат вывода, обязательные секции, ограничения (что нельзя делать), требования к чеклистам.

## Обоснование

Если модель получает только имя скилла (`/aif-plan`) без инструкций, она не знает, что именно должен делать этот скилл. Результат — генерация произвольного текста вместо структурированного плана, потеря связи с задачей, множественные циклы перезапуска стадий. Полная доставка инструкций обеспечивает детерминированное поведение модели независимо от типа рантайма.
