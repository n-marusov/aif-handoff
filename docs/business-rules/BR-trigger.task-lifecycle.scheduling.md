# BR-trigger.task-lifecycle.scheduling — Отложенный запуск задачи

> Задача в Backlog может быть запланирована на будущий автоматический запуск; запуск одноразовый.

## Правило

Задача может иметь момент запланированного старта. По наступлении этого момента задача автоматически переводится в стадию Planning тем же путём, что и ручной запуск AI. Запланированный запуск одноразовый: после срабатывания расписание снимается.

## Детализация

- Запланировать можно только будущий момент; момент в прошлом отклоняется. Снятие расписания — отдельная операция.
- Запуск выполняется только если к моменту срабатывания задача всё ещё находится в Backlog, не приостановлена и не взята другим путём; конкурентное взятие исключено.
- Срабатывание откладывается, если рабочая копия проекта содержит незафиксированные изменения предыдущей задачи.
- Задачи под владением человека расписанием не запускаются.

## Обоснование

Позволяет выстраивать отложенную работу (например, запуск в ночном окне), не нарушая порядок постановки задач в Backlog и не допуская конфликтов с другими задачами проекта.
