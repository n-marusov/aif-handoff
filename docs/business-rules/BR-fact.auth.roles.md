# BR-fact.auth.roles — Роли участников

> Участники имеют одну из двух ролей — Admin или Member, — определяющую объём доступных действий.

## Правило

Каждый участник имеет ровно одну роль. Роль определяет объём доступных действий и не может быть определена неявно.

| Роль       | Действия                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| **Admin**  | Любые действия над любой задачей, управление назначениями, управление участниками и настройками.     |
| **Member** | Действия только над задачами, к которым участник назначен. Самоназначение на задачи без исполнителя. |

## Детализация

- Режим участников — отдельный политический слой, включаемый конфигурацией; при его отключении роли не применяются и разграничение доступа не действует.
- Новый участник по умолчанию получает роль Member.
- Роль может быть изменена только администратором; смена роли отзывает активные сессии участника.
- Неактивный участник не обладает правами, независимо от роли.

## Обоснование

Две роли покрывают базовый принцип наименьших привилегий: обычный участник действует в границах своих задач, администратор управляет системой и участниками.
