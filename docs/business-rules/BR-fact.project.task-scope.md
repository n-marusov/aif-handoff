# BR-fact.project.task-scope — Принадлежность задачи проекту

> Каждая задача принадлежит ровно одному проекту; проект изолирует задачи, их стадии, участников и настройки.

| **Приоритет** | Высокий                      |

## Правило

Задача существует в контексте проекта и не может принадлежать нескольким проектам. Конвейер, настройки runtime, участники и порядок задач определяются в границах проекта.

## Детализация

- Список задач запрашивается в границах проекта; операция без указания проекта отклоняется.
- Порядок задач и авто-очередь действуют в пределах проекта.
- Настройки профилей runtime разрешаются с учётом проекта.
- Операции над задачей не затрагивают задачи других проектов.

## Обоснование

Изоляция по проекту обеспечивает независимость конвейеров, корректность настроек и предсказуемый порядок обработки задач.
