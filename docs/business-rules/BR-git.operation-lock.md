# BR-git.operation-lock — Сериализация Git-операций

> Изменяющие состояние репозитория Git-операции сериализуются по проекту и никогда не удерживаются во время выполнения модели.

## Правило

Git-операции, изменяющие состояние репозитория (коммиты, ветки, рабочие деревья), выполняются последовательно в пределах одного проекта. Блокировка удерживается только на время самой Git-операции и не охватывает выполнение модели или runtime.

## Детализация

- Блокировка имеет единый ключ — нормализованный путь проекта.
- Блокировка всегда освобождается, в том числе при ошибке операции.
- Длительное ожидание в очереди на блокировку фиксируется как предупреждение, чтобы выявлять узкие места.
- Выполнение модели и runtime никогда не оборачивается в эту блокировку, чтобы не сериализовать дорогие операции без необходимости.

## Обоснование

Предотвращает одновременные конфликтующие изменения одного репозитория, не превращая Git-лок в глобальный тормоз для параллельной работы агентов.
