# BR-automation.auto-queue — Автоматическая очередь

> Автоматическая очередь наполняет конвейер проекта до заданной глубины, переводя задачи из Backlog в Planning в порядке постановки.

## Правило

В режиме автоматической очереди система поддерживает заполненность конвейера проекта: пока число активных задач меньше допустимой глубины, следующая задача из Backlog переводится в Planning.

## Детализация

- Порядок обработки — по позиции в Backlog (FIFO); создание обычной задачи добавляет её в конец.
- Глубина очереди: для последовательного проекта — одна задача; для параллельного — до настроенного предела одновременных задач проекта.
- Очередь не наполняется, если проект достиг предела.
- Очередь приостанавливается для проекта, если есть задача с блокирующим состоянием фиксации изменений, либо если общая рабочая копия содержит незафиксированные изменения предыдущей задачи.
- Перевод задачи из Backlog выполняется атомарным захватом, что исключает гонку с расписанием, другим координатором или ручным запуском.
- Задачи под владением человека и приостановленные задачи в очередь не попадают.

## Обоснование

Автоматическое наполнение устраняет простой конвейера, а строгий порядок и атомарный захват — дублирование и конфликты между параллельными путями запуска.
