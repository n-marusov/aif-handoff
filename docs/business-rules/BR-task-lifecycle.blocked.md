# BR-task-lifecycle.blocked — Приостановка из-за внешней блокировки

> Задача может быть приостановлена на любой стадии при внешней блокировке и при возобновлении возвращается на ту стадию, с которой была заблокирована.

| Поле          | Значение                    |
| ------------- | --------------------------- |
| **ID**        | `BR-task-lifecycle.blocked` |
| **Домен**     | `task-lifecycle`            |
| **Статус**    | Принято                     |
| **Приоритет** | Высокий                     |

## Правило

При возникновении внешней зависимости (лимит провайдера, временный сбой, недоступность внешней системы, необходимость ручного решения) задача переводится в состояние `Blocked (External)`. Система запоминает стадию, предшествовавшую блокировке, и возвращает задачу именно на неё при снятии блокировки.

## Детализация

- Вместе с блокировкой фиксируются причина и момент повторной попытки.
- Возобновление возвращает задачу на исходную стадию и очищает состояние блокировки.
- Автоматическое возобновление возможно при наступлении срока повторной попытки. Количество автоматических повторов ограничено; после исчерпания лимита задача переводится в режим ручного разбора без дальнейших автоповторов.
- Блокировка может быть инициирована автоматически (сбой, лимит) или явно (требуется решение оператора) — в обоих случаях дальнейшее автоматическое продвижение прекращается.
- Пока задача заблокирована, повторный запуск стадии и продвижение по конвейеру не выполняются.

## Обоснование

Отделение «внешней блокировки» от «сбоя выполнения» позволяет не терять прогресс: задача не перезапускается с нуля, а продолжается с точки остановки после устранения внешней причины.
