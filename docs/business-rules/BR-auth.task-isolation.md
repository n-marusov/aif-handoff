# BR-auth.task-isolation — Изоляция задач под владением AI

> Участник, не являющийся администратором, не может действовать над задачей под владением AI.

## Правило

Задача, исполняемая автоматическим агентом, недоступна для действий участника-неадминистратора даже при наличии назначения. Действовать над ней может только администратор (или сам агент). Чтобы участник мог действовать над задачей, она должна быть передана под владение человека.

## Детализация

- Действие участника над задачей под владением AI отклоняется как неавторизованное.
- Исключение — администратор, для которого ограничение по владельцу не действует.
- Передача задачи человеку (или участнику) выполняется отдельной операцией handoff.
- Ограничение не запрещает просмотр и комментирование в пределах доступного проекта.

## Обоснование

Предотвращает конфликт между человеком и автоматическим агентом, одновременно изменяющими одну задачу, и защищает целостность автоматического конвейера.
