# BR-fact.project.runtime-profiles — Профили runtime проекта

> Каждый проект может иметь профили runtime для различных этапов (планирование, выполнение, ревью, чат); при отсутствии профиля проекта используется общесистемный.

## Правило

Для каждого этапа обработки задачи может быть задан профиль runtime на уровне проекта. Разрешение профиля каскадное: переопределение задачи → значение проекта → общесистемное значение по умолчанию.

## Детализация

- Этапы, для которых может быть задан профиль: задача (выполнение), планирование, ревью, чат.
- Явное переопределение на уровне задачи имеет приоритет над проектом и системой.
- Если профиль не задан нигде, применяется системный профиль по умолчанию.
- Смена AI-провайдера выполняется на уровне профиля, без изменения кода системы.

## Обоснование

Каскадное разрешение профилей позволяет использовать разные модели и провайдеры для разных этапов и проектов, не усложняя конфигурацию всей системы.
