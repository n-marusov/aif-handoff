# BR-constraint.project.no-auto-agent-infra — Запрет авто-добавления агентской инфраструктуры

> Агентская инфраструктура (`.claude/`, `CLAUDE.md` и аналогичные файлы конфигурации агентов) не добавляется в проект автоматически — только по явному действию пользователя.

## Правило

AI-агенты и инструменты настройки проекта (включая `/aif`, `/aif-fix`, `/aif-plan` и другие скиллы AI Factory) не должны автоматически создавать в проекте агентскую инфраструктуру — директорию `.claude/`, файл `CLAUDE.md`, `.mcp.json` или любые другие файлы и директории, предназначенные для конфигурации AI-агентов, без явного запроса или одобрения пользователя.

## Детализация

- Запрет распространяется на любые автоматические операции создания, записи или генерации файлов/директорий агентской инфраструктуры.
- Разрешено:
  - Создание `.claude/agents/` по явной команде пользователя (например, через MCP Install в Web UI).
  - Создание `CLAUDE.md` по явной команде пользователя.
- Запрещено:
  - Автоматическое создание `.claude/`, `CLAUDE.md` в процессе `/aif setup`, `/aif-fix`, `/aif-plan` или аналогичных команд без предварительного согласования с пользователем.
  - Добавление записей в `.mcp.json` без явного действия пользователя.
  - Создание любых файлов конфигурации агентов в корне проекта как побочный эффект выполнения скилла.
- Правило действует на все проекты, включая текущий. Наличие рукописного `CLAUDE.md` или `.claude/` не отменяет запрет на их автоматическое изменение.

## Обоснование

1. **Предсказуемость:** Пользователь должен контролировать, какая агентская инфраструктура попадает в проект. Автоматическое создание приводит к неожиданным изменениям в проекте.
2. **Чистота репозитория:** Агентские конфигурации не должны попадать в VCS без ведома пользователя. Их автоматическое создание повышает риск случайного коммита агент-специфичных файлов.
3. **Безопасность:** Файлы конфигурации агентов (`.mcp.json` с токенами, `CLAUDE.md` с инструкциями) не должны создаваться без явного согласования — это снижает риск утечки конфиденциальных данных.
4. **Переносимость:** Не все пользователи используют одного и того же агента (Claude Code, Codex, Cline и т.д.). Автоматическое создание инфраструктуры под конкретного агента навязывает экосистему.
