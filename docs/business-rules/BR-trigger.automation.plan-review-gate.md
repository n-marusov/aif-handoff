# BR-trigger.automation.plan-review-gate — Гейт ревью плана

> Для задач, связанных с внешней системой ревью (VCS-issue), план перед реализацией публикуется и требует утверждения человеком; без утверждения реализация не начинается.

## Правило

Задача после завершения планирования переходит в стадию `Plan Review` и не начинает реализацию, пока не получит разрешения — от человека (`approve_plan`) либо автоматически (`autoMode`). Для задач, связанных с внешней VCS-системой, разрешение запрашивается через публикацию плана как черновика PR/MR.

## Детализация

- Гейт действует на всех задачах после завершения планирования. Публикация плана выполняется детерминированным коммитом, включающим только план задачи и разрешённые служебные пути; наличие посторонних изменений блокирует публикацию.
- Публикация не выполняется без зафиксированной ветки задачи и без файла плана — задача остаётся в `Plan Review` для повторной попытки.
- Опубликованный план оформляется как черновик PR/MR, который не закрывает issue.
- Задача остаётся в `Plan Review` до утверждения; при запросе изменений возвращается к доработке (improve) с сохранением связи и обратной связи.
- Реализация не запускается, пока план не утверждён; это правило действует и для задач, перемещённых вручную.
- При финальной публикации используется тот же PR/MR, и только после этого к нему добавляется закрывающее issue указание.

## Обоснование

Гейт ревью плана даёт человеку точку контроля до начала реализации, снижая стоимость ошибок планирования и объём переработки.
