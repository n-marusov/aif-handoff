# BR-inference.ownership.automation-eligibility — Допуск задачи к автоматизации

> Автоматизация обрабатывает только задачи под владением AI, не приостановленные и не удерживаемые блокировкой.

## Правило

Автоматический конвейер рассматривает к исполнению только задачи, одновременно удовлетворяющие условиям: владелец — AI, задача не приостановлена, задача не удерживается активной блокировкой. Все прочие задачи не выбираются ни одним автоматическим путём.

## Детализация

- Задачи под владением человека исключаются на единой границе выборки данных из претендентов координатора, расписания, авто-очереди, восстановления watchdog, ожидания разрешений и потребления бюджета провайдера.
- Перед запуском стадии владение перепроверяется; при смене владельца выполнение прерывается.
- Приостановка задачи немедленно исключает её из автоматических претендентов, но не прерывает уже запущенную сессию.
- Взятие задачи в работу атомарно: задача захватывается только в ожидаемом состоянии (владелец, стадия, авто-режим, отсутствие блокировки).

## Обоснование

Исключает вмешательство автоматизации в задачи под управлением человека и предотвращает двойной запуск одной задачи разными путями.
