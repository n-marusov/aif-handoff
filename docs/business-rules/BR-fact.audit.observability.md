# BR-fact.audit.observability — Наблюдаемость выполнения и ошибок

> Выполняющиеся агенты передают периодические сигналы активности; ошибки классифицируются по категориям; изменения состояния транслируются в реальном времени.

## Правило

Система обеспечивает наблюдаемость процесса: активность агентов отмечается периодически, ошибки выполнения классифицируются по категориям, а изменения состояния задач транслируются потребителям в реальном времени.

## Детализация

- Выполняющийся агент периодически отмечает активность; своевременность действий задачи также отражается отдельной меткой.
- По периоду молчания интерфейс отличает «работает» от «зависло».
- Ошибки выполнения классифицируются по категориям (лимит частоты, аутентификация, тайм-аут, доступ и др.), а не по тексту сообщения.
- События активности фиксируются немедленно (по умолчанию), при этом пакетная запись может включаться конфигурацией.
- Каждое изменение состояния задачи транслируется всем потребителям (интерфейс получает обновления по WebSocket).
- Задачи, не подававшие признаков активности дольше порога, считаются устаревшими.

## Обоснование

Наблюдаемость сокращает время обнаружения и диагностики проблем, а поток обновлений в реальном времени поддерживает актуальность статусов для всех участников.
