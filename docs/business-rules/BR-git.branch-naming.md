# BR-git.branch-naming — Именование ветки задачи

> Работа над задачей ведётся в отдельной ветке; имя ветки формируется по конвенции проекта — префикс ветки и идентификатор задачи.

| Поле          | Значение               |
| ------------- | ---------------------- |
| **ID**        | `BR-git.branch-naming` |
| **Домен**     | `git`                  |
| **Статус**    | Принято                |
| **Приоритет** | Высокий                |

## Правило

Каждая задача, связанная с внешней системой работ, получает отдельную ветку. Имя ветки детерминированно формируется из настроенного префикса и идентификатора внешней задачи и служит единым источником истины для всех путей создания рабочего дерева.

## Детализация

- Имя ветки не зависит от идентификатора задачи во внутренней БД и формируется по внешней связи (провайдер + номер задачи).
- Префикс ветки — часть конвенции проекта (см. `BR-git.convention-resolution`).
- Имя ветки, зафиксированное при первой публикации, повторно используется при последующих операциях (перепланирование, финальная публикация).
- Рабочее дерево задачи привязывается к ветке, а не к задаче (см. `BR-git.worktree-isolation`).

## Обоснование

Детерминированное имя ветки обеспечивает воспроизводимость, однозначную связь задачи и ветки и корректную работу изоляции и повторных публикаций.
