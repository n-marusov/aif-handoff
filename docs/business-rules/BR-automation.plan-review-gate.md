# BR-automation.plan-review-gate — Гейт ревью плана

> Для задач, связанных с внешней системой ревью (VCS-issue), план перед реализацией публикуется и требует утверждения человеком; без утверждения реализация не начинается.

## Правило

При включённом гейте ревью плана задача, связанная с внешним issue, останавливается на стадии `Plan Review` после публикации плана и не переходит к реализации до явного утверждения человеком во внешней системе.

## Детализация

- Гейт действует только при включённой функции и наличии связи задачи с внешним issue.
- Публикация плана выполняется детерминированным коммитом, включающим только план задачи и разрешённые служебные пути; наличие посторонних изменений блокирует публикацию.
- Публикация не выполняется без зафиксированной ветки задачи и без файла плана — задача остаётся в `Plan Ready` для повторной попытки.
- Опубликованный план оформляется как черновик PR/MR, который не закрывает issue.
- Задача остаётся в `Plan Review` до утверждения; при запросе изменений возвращается к планированию с сохранением связи и обратной связи.
- Реализация не запускается, пока план не утверждён; это правило действует и для задач, перемещённых вручную.
- При финальной публикации используется тот же PR/MR, и только после этого к нему добавляется закрывающее issue указание.

## Обоснование

Гейт ревью плана даёт человеку точку контроля до начала реализации, снижая стоимость ошибок планирования и объём переработки.
