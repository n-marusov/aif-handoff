# BR-automation.pipeline — Автоматическое продвижение по конвейеру

> Система автоматически продвигает задачу по стадиям конвейера; для каждой стадии определены условия входа и выхода.

## Правило

Для задачи под владением AI система выполняет стадийные шаги (планирование, улучшение плана, проверка плана, публикация, реализация, верификация, ревью) и переводит задачу на следующую стадию только при успешном завершении текущего шага. Каждый шаг имеет определённые условия входа и выхода и выполняется в рамках выбранного runtime-профиля.

## Детализация

- **Planning → Plan Review**: успешное планирование.
- **Improve → Plan Review**: успешное улучшение плана.
- **Plan Review**: проверка плана выполняется на месте и не меняет стадию при успехе.
- **Plan Review → Plan Review**: публикация плана (план остаётся в Plan Review, опубликованный для ревью).
- **Plan Review / Implementing → Verify**: успешная реализация.
- **Verify → Review**: успешная верификация.
- **Review → Done**: успешное ревью (если не требуется ручное ревью).
- Ошибка или невыполнение условий на любом шаге останавливает продвижение и передаётся обработчику сбоев.

## Обоснование

Единый конвейер делает процесс обработки изменения воспроизводимым и наблюдаемым, а результат — предсказуемым без ручного управления каждым шагом.
