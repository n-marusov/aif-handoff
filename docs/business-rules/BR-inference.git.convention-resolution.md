> Конвенции именования веток и коммитов разрешаются в порядке приоритета: явные правила проекта → настройки проекта → общесистемные значения по умолчанию.

## Правило

Конвенции именования веток и коммитов определяются по строгому приоритету источников: сначала явное объявление в правилах проекта, затем настройки проекта, затем общесистемные значения по умолчанию.

## Детализация

- Явное объявление читается из раздела о Git-конвенциях в файлах правил проекта.
- Если явного объявления нет, используется префикс ветки из настроек проекта.
- Если конвенция не задана нигде, применяются общесистемные значения по умолчанию.
- Использование значения по умолчанию сопровождается предупреждением, чтобы оператор видел отсутствие заданной конвенции.
- Разрешённая конвенция применяется единообразно всеми путями создания веток и коммитов.

## Обоснование

Единый порядок разрешения конвенций исключает расхождение имён веток и сообщений коммитов между компонентами системы и делает поведение предсказуемым.
