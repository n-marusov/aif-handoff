# ADR-IMPL.UI.react-vite-tailwind-adoption

**Статус:** ПРИНЯТО
**Дата:** 2026-09-14
**Контекст:** Web-интерфейс AIF Handoff — Kanban-доска с Drag-and-Drop, управление задачами, чат и администрирование. Без выбранного стека UI разработка шла бы ad-hoc (jQuery, Alpine, любой шаблонизатор), что не соответствует современным стандартам DX, производительности и масштабируемости.

**Требование-источник:** `vision.md` §1.3 HF-1–HF-4, `vision.md` §2.4 (границы UI), `docs/architecture.md`

**Решение:** React 19 + Vite для сборки и TypeScript. Интерфейс строится на TailwindCSS 4 с семантическими токенами (light/dark темы). Vite обеспечивает HMR в разработке и оптимизированную production-сборку (code-splitting, tree-shaking, CSS purging через Tailwind). React 19 даёт Suspense-совместимость, улучшенный SSR (если потребуется), и стабильный API для кастомных хуков и компонентов. Reusable UI-примитивы выделены в `packages/web/src/components/ui/` (Button, Dialog, Badge, CommandPalette). Компоненты стейтов (задачи, проекты) — в feature-папках: `components/kanban/`, `components/task/`, `components/project/`.

**Рассмотренные альтернативы:**

- **Next.js** — full-stack React с SSR. Отвергнуто: SSR не нужен — приложение SPA с Hono API; Next.js добавляет Server Components, routing, и лишнюю сложность для чисто клиентского Kanban.
- **Vue 3 + Nuxt** — альтернативный стек. Отвергнуто: проект на TypeScript, React — де-факто стандарт для сложных SPA; переучивание команды неоправданно.
- **Svelte + SvelteKit** — легковесный, но менее зрелый для комплексных интерфейсов с DnD и WebSocket. Отвергнуто: меньшая экосистема библиотек (DnD, Query, WS).
- **CSS Modules / styled-components вместо Tailwind** — полноценная CSS-in-JS. Отвергнуто: Tailwind v4 с дизайн-токенами даёт единообразную стилизацию, нулевую рантайм-нагрузку (JIT-компиляция) и встроенную поддержку тёмной темы.

**Последствия:**

- **Положительные:** быстрая разработка UI через Tailwind-утилиты; React 19 + Vite — современный, быстрый, хорошо документированный стек; семантические CSS-переменные для тем.
- **Отрицательные:** Tailwind-классы раздувают JSX; запрет на тяжёлые CSS-свойства (box-shadow, backdrop-filter) — осознанное ограничение для производительности. React 19 — новая версия с потенциальными breaking changes в экосистеме.
- **Смягчение:** компоненты-примитивы (`ui/`) инкапсулируют Tailwind-классы; в новых версиях — контрольная проверка совместимости зависимостей перед обновлением.
