# ADR-DES.PROCESS.correlation-first-async-traces

**Статус:** ПРЕДЛОЖЕНО
**Дата:** 2026-09-18
**Контекст:** Задача проходит стадии (`backlog → planning → improve → plan_review → implementing → verify → review → done → accepted`), но переход между стадиями — не вызов: `agent` забирает работу из SQLite поллингом каждые 30 секунд, дополненным wake-каналом по WebSocket (`packages/agent/src/coordinator.ts`, `wakeChannel.ts`). Заголовок W3C trace context не пересекает границу поллинга, и «трасса задачи» физически распадается на независимые прогоны. Хвостовая выборка в Collector требует получения всех спанов трассы одним экземпляром в пределах окна `decision_wait` — трасса, живущая часами, этому противоречит. Дополнительно предполагается AI-разбор телеметрии на стороне, имеющей доступ к исходному коду приложения: содержание промптов в телеметрии не является необходимым условием анализа.

**Требование-источник:** `BR-fact.audit.observability`, `BR-constraint.audit.immutable-trail`, `BR-constraint.ownership.executor-history`, `REQ-NFR-ops.observability.audit-trail-completeness`, `.ai-factory/references/opentelemetry-genai-semconv.md`, evidence: `packages/agent/src/coordinator.ts`, `packages/data/src/taskTransitions.ts`, `packages/data/src/audit.ts`, `packages/agent/src/queryAudit.ts`

**Решение:** Приоритет — **корреляция, а не полнота содержимого**.

1. **Единица трассировки — прогон стадии** (bounded по времени, совместим с хвостовой выборкой): корневой спан `invoke_workflow {aif.stage}`; внутри — `invoke_agent {gen_ai.agent.name}` для вызова адаптера, `execute_tool {gen_ai.tool.name}` для инструментов, `chat`/`generate_content` для запросов к модели.
2. **Логическая трасса задачи собирается по ключу** `aif.task.id` (атрибут, не имя спана и не метка метрик). Соседние прогоны связываются **span links** с `aif.link.type` (`stage_transition`, `retry`, `queue_handoff`, `tool_call`).
3. **Контекст переносится через базу явно:** ссылка на родительский `traceparent` сохраняется на существующей иммутабельной записи истории исполнителей/аудита, создаваемой атомарно с переходом задачи (`packages/data/src/taskTransitions.ts`, `audit.ts`). Новая таблица не вводится; расширение существующей — append-only миграция по правилу версионирования.
4. **Содержимое по умолчанию не захватывается:** `gen_ai.input.messages`, `gen_ai.output.messages`, `gen_ai.system_instructions`, `gen_ai.tool.call.arguments`/`result` — только по явному включению (`AIF_TELEMETRY_CONTENT_CAPTURE=false`), с redaction (`redactProviderText`) и усечениями по образцу `queryAudit.ts`. В спанах остаются идентификаторы, категории, количества, длительности. `gen_ai.conversation.id` — только реальный `sessionId` адаптера; синтез из UUID/trace id/хэша запрещён semconv.
5. **Два контура потребления на одном пайплайне:** operational (Tempo/Loki/Prometheus — «что происходит сейчас») и AI-аналитика (нормализованный correlation feed + доступ к коду — «почему и что дальше»). Хранилище и признаки AI-контура — отложенное решение.

**Рассмотренные альтернативы:**

- **Одна трасса на всю жизнь задачи** (включая детерминированный trace id из UUID задачи). Отвергнуто: трасса живёт часами/днями; хвостовая выборка не принимает решение (все спаны должны попасть в один экземпляр Collector в окне `decision_wait`); лимиты памяти (`num_traces`, `maximum_trace_size_bytes`) расходуются на единицы данных.
- **Только атрибуты, без span links.** Отвергнуто: запрос по `aif.task.id` сохраняется, но причинно-временной граф прогонов не восстанавливается в визуализации.
- **Полный захват промптов/выводов «для AI».** Отвергнуто: PII клиентов, стоимость хранения, лимиты Loki на structured metadata; код уже доступен анализирующей стороне.
- **Синтез `gen_ai.conversation.id` из `aif.task.id`.** Отвергнуто semconv-запретом на фолбэки для conversation id.

**Последствия:**

- **Положительные:** трассировки коротки и полностью покрываются выборкой; сквозная картина задачи — запросом по `aif.task.id` независимо от числа процессов и прошедшего времени; минимальный объём и чувствительность данных; AI-контур получает признаки, достаточные для гипотез, а «почему код так себя ведёт» уточняет по исходникам.
- **Отрицательные:** links поддержаны не всеми интерфейсами (в Grafana переход может требовать ручной навигации); перенос `traceparent` добавляет поля в существующие записи истории; при недоступности Collector восстановление логической трассы ограничивается атрибутами.
- **Смягчение:** `aif.task.id` дублируется во всех записях как основной ключ — links остаются улучшением визуализации; носитель `traceparent` выбирается из уже иммутабельных записей с соблюдением append-only правила; для stdio-MCP — синхронный экспорт спанов, чтобы не терять данные при намеренно синхронном `process.exit(0)`.
