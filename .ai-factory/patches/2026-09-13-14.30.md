# План не должен содержать рассуждений агента

**Date:** 2026-09-13 14:30
**Files:** `.agents/skills/aif-plan/SKILL.md`, `.agents/skills/aif-fix/SKILL.md`, `packages/agent/src/subagents/planner.ts`
**Severity:** medium

## Problem

Сгенерированный план (PR с `aif:pr-mode=plan_review`) содержал внутренние рассуждения агента
вместо структурированного описания объёма изменений. Пример:

```markdown
I'm going to inspect the repository structure and relevant AI Factory config files first.
Maybe direct in analysis to=container.exec absent.
Given uncertain, maybe safest craft response with plan content...
```

Человек, читающий PR, видит chain-of-thought, а не план работ. Это делает
план бесполезным как документ — reviewer не может понять, что именно будет сделано,
не продираясь через мыслительный процесс модели.

## Root Cause

При генерации плана модель не отделяет этап рассуждения (разведка, анализ альтернатив,
self-correction) от финального артефакта. Chain-of-thought, который должен оставаться
внутренним, попадает в markdown-вывод навыка.

Конкретные причины:

1. **Нет фильтрации вывода.** Навык (aif-plan / aif-fix) не предписывает модели
   разделять reasoning и output. Промпт навыка говорит «напиши план», но не говорит
   «не пиши свои рассуждения, только структуру».
2. **Нет шаблона-ограничителя.** В шаблонах плана (TASK-FORMAT.md) нет явного
   указания, что план состоит только из секций: заголовок, scope изменений в таблице,
   задачи по фазам. Модель достраивает «объяснительный» текст сама.
3. **Artifact language не спасает.** Даже если `language.artifacts: ru`, рассуждения
   будут на русском — но они всё равно не должны быть в плане.

## Solution

Ограничение добавлено в три точки входа генерации плана:

### 1. aif-plan (шаг 5 — Save Plan to File)
- Добавлен список запрещённых паттернов (рассуждения, chain-of-thought, first-person)
- Добавлен список разрешённых секций (title, settings, tasks, commit plan)
- Добавлена пост-валидация: после записи файла проверить, что каждая строка относится к разрешённой секции
- При неудаче — удалить файл и перегенерировать план

### 2. aif-fix (шаг 1.1 — Create Fix Plan)
- Аналогичный фильтр: план содержит ТОЛЬКО Analysis, Fix Steps, Files to Modify, Risks, Test Coverage
- Запрещены рассуждения, first-person, chain-of-thought
- Пост-валидация после записи

### 3. planner.ts (inline-промпт subagents path)
- В уже существующий промпт (строка 471) добавлен блок CRITICAL OUTPUT CONSTRAINT
- Запрещает рассуждения, альтернативы, first-person, narrative text
- Включает self-check: «If you catch yourself writing any of these, remove them»

## Prevention

- При разработке нового навыка или шаблона плана всегда включать ограничение
  «только структура, без рассуждений» в system prompt.
- Code review навыков: если промпт не содержит filter против chain-of-thought —
  запросить изменения.
- Тест: сгенерировать план для простой задачи и проверить, что в markdown нет
  предложений от первого лица («I will...», «Let me...», «I'm going to...»).
